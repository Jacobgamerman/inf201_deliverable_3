# INF201 - Deliverable 3: Mini-RPG Battle Simulator

This repository contains the implementation of a turn-based mini-RPG battle simulator developed for Deliverable 3 in INF201. The project expands on basic character mechanics by applying object-oriented programming principles such as encapsulation, composition, and inheritance[cite: 1, 2].
